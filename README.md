# 《午後來訪》— 輕量互動視覺小說網頁遊戲

網站連結：

https://yukiya-create-botttttttt.github.io/afternoon-visit/
(底下有全結局通關攻略)

一個安靜溫暖的午後，窗外微風拂過，你來到一間明亮簡約的房間，與少女「晴夏」展開一段愜意的午後茶聚時光。

本專案為完全基於 **HTML5、CSS3、Vanilla JavaScript** 開發的原生互動視覺小說（Visual Novel）網頁遊戲，不依賴任何外部框架或套件，開箱即玩，並針對 GitHub Pages 部署進行了最佳化。

---

## 🎮 遊戲特色

1. **純原生技術開發（Vanilla Web Stack）**
   - 僅使用原生 HTML5、CSS3 與 Vanilla JavaScript (ES6+)。
   - 無需安裝 Node.js、npm 或任何大型框架（React / Vue 等）。
   - 零外部 CDN、零外部字型或圖庫依賴，完全離線可用。

2. **向量 SVG 視覺素材**
   - 包含溫暖午後室內背景、動漫風格立繪表情與控制圖標，均為本地高畫質向量 SVG。
   - 檔案極致輕量（全專案總大小小於 100KB），極速載入且在高解析度螢幕（Retina / 4K）上永不模糊失真。

3. **豐富的角色互動系統（Character Touch System）**
   - **區域觸控反饋**：角色立繪劃分有「頭部」、「身體」與「互動」三個可點擊區域，點擊不同部位會觸發不同的即時語音與表情。
   - **情緒累積反饋**：短時間內連續觸碰角色時，晴夏的反應會逐步升級（正常反應 ➔ 害羞驚訝 ➔ 可愛嬌嗔），不再只是重複單一句子。
   - **隱藏心動彩蛋**：當好感度達到 70 以上時，點擊角色有機率解鎖專屬隱藏心動台詞與心動音效。
   - **操作冷卻保護**：內建 1.5 秒冷卻防重複點擊，避免文字快速閃爍與重疊。

4. **自主主動對話（Idle System）**
   - 玩家若在遊戲中發呆或閒置約 15 秒，晴夏會主動開口向玩家搭話，讓角色彷彿擁有真實的生命力。

5. **好感度與多重結局分支**
   - 起始好感度為 50，範圍限制在 0～100 之間。
   - 玩家的每一個回答與互動選擇都會即時影響好感度數值與愛心進度條。
   - 根據最終好感度呈現三種不同結局：
     - **80～100【特別結局：約定明日的午後】**：晴夏害羞地與你約定明日再次造訪，牽絆深刻。
     - **40～79【普通結局：溫暖的午後茶聚】**：舒適溫暖的道別，期待未來的平淡相遇。
     - **0～39【冷淡結局：短暫的沈默告別】**：略顯客氣與疏離的簡短告別。

6. **貼心輔助功能**
   - **對話回顧（LOG）**：隨時點擊右上角「回顧」按鈕，即可開啟歷史對話紀錄面板，不用擔心錯過台詞。
   - **遊戲設定**：支援打字速度調節（悠閒 / 標準 / 快速 / 瞬間顯示）、Web Audio 原生合成音效開關、劇情自動播放（Auto）。
   - **自動存檔**：好感度與偏好設定自動透過 `localStorage` 儲存於本機。

## 🕹️ 遊玩方式

1. **直接開啟**：
   - 使用任何現代瀏覽器（Google Chrome、Edge、Safari、Firefox）直接雙擊開啟 `index.html` 即可立即開始遊玩。

2. **操作控制**：
   - **推進對話**：點擊對話框任一處，或按下鍵盤 **空白鍵 (Space)** / **Enter 鍵**。
   - **加速略過打字**：文字正在逐字顯現時點擊對話框，可立即顯示整句。
   - **選擇選項**：在出現分支按鈕時，點擊心儀的選項推進不同劇情線。
   - **角色互動**：滑鼠移至晴夏的頭部、胸前衣飾或周邊時，指標會變為點擊手勢，點擊即可觸發互動。

### 🌟 結局一：特別結局【約定明日的午後】（好感度 80～100）

- **結局特點**：晴夏臉頰微紅、緊緊拉住你的衣角，羞怯地向你約定明天同個時間一定要再來找她，牽絆深刻。
- **解鎖條件**：最終結算好感度達到 **80 分以上**。
- **最佳推薦路線**：
  1. 分支一選擇：**「很充實，見到妳更開心了！」**（好感度 +10 ➔ 60）
  2. 分支二選擇：**「想聽妳聊聊最近讀的書。」**（好感度 +10 ➔ 70，此時已跨越心動門檻！）
  3. 分支三選擇：**「晴夏今天泡的茶真的很好喝。」**（好感度 +10 ➔ 80）
  - 結算好感度達 **80 分**，完美解鎖特別結局！

---

### 🍵 結局二：普通結局【溫暖的午後茶聚】（好感度 40～79）

- **結局特點**：晴夏笑容燦爛地向你揮手道別，享受了一段平淡安穩、回味無窮的午後茶聚時光。
- **解鎖條件**：最終結算好感度介於 **40 ～ 79 分**。
- **通關路線範例**：
  1. 分支一選擇：**「普普通通，就是平凡的一天。」**（好感度 +5 ➔ 55）
  2. 分支二選擇：**「靜靜享受茶香和微風就好。」**（好感度 +5 ➔ 60）
  3. 分支三選擇：**「窗邊擺的那盆植物長得真漂亮。」**（好感度 +5 ➔ 65）
  - 結算好感度達 **65 分**，達成溫馨平淡的普通結局。

---

### 🍂 結局三：冷淡結局【短暫的沈默告別】（好感度 0～39）

- **結局特點**：晴夏神情略顯失落與困惑，客氣且略帶距離感地收拾茶杯，平淡而尷尬地互道再見。
- **解鎖條件**：最終結算好感度在 **39 分以下**。
- **觸發方式**：
  1. 分支一選擇：**「有點累，心情不太好……」**（好感度 -5 ➔ 45）
  2. 分支二選擇：**「其實我待會還有事情要忙……」**（好感度 -5 ➔ 40）
  3. （若之前存檔曾經歷負面選擇，使分數降至 40 分以下），即可觸發冷淡疏離的告別。

## 🚀 部署至 GitHub Pages 教學

若你想將本遊戲發布到網路上與朋友分享，可透過 GitHub Pages 免費託管：

### 方法一：將 `visual-novel` 資料夾作為根目錄推送
1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如 `afternoon-visit`。
2. 將 `visual-novel` 目錄中的所有內容推送至 GitHub 的 `main` 分支：
   ```bash
   cd visual-novel
   git init
   git add .
   git commit -m "feat: 初版發布《午後來訪》"
   git branch -M main
   git remote add origin https://github.com/<你的使用者名稱>/afternoon-visit.git
   git push -u origin main
   ```
3. 前往 GitHub 儲存庫頁面，點選 **Settings（設定）** ➔ 側邊欄點選 **Pages**。
4. 在 **Build and deployment** 底下的 **Source** 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
6. 等待 1～2 分鐘，即可透過 `https://<你的使用者名稱>.github.io/afternoon-visit/` 直接在線上遊玩！

## 🛠️ 客製化與擴展建議

本專案程式碼結構清晰，註解詳盡，初學者可輕鬆調整與修改：
- **修改對話與選項**：在 `script.js` 中的 `DIALOGUE_NODES` 物件中新增或修改對話文字與選項走向。
- **調整好感度加減**：在各選項的 `favorDelta` 屬性調整加減數值。
- **增加新表情**：將新的 SVG/WebP 立繪放入 `assets/character/`，並在 `setExpression()` 中增加名稱對應即可。
